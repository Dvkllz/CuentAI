# CuentAI 0.2.2 · Conexión automática en Android

## Cambios

- Conserva la IP Wi-Fi integrada para teléfonos físicos.
- Si esa dirección no responde dentro del emulador, prueba automáticamente el túnel de `adb` y `10.0.2.2` para llegar al servidor del computador.
- No vuelve a mostrar opciones técnicas de conexión en la interfaz.
- Versión Android `versionCode 5` y `versionName 0.2.2`.
